## 🌟 Overview

The **Disneyland Reviews Sentiment NLP & 4D Explorer** transforms guest feedback into a multi-dimensional intelligence ecosystem. Benchmarking experiences across *Disneyland California, Disneyland Paris, and Disneyland Hong Kong*, this platform integrates automated sentiment polarity extraction, 3D coordinate morphospaces, interactive global guest origin globes, and real-time TF-IDF machine learning star rating forecasting.

## ✨ Features & Visual Dimensions

### 📊 1. 2D Branch Sentiment & Ratings
- **Cross-Branch Rating Distributions**: Stacked comparative breakdowns of 1-to-5 star ratings for California, Paris, and Hong Kong parks.
- **Polarity vs. Subjectivity Spectrum**: Two-dimensional density distribution revealing how emotional intensity correlates with perceived value.

### 🌐 2. 3D Sentiment Morphospace & Planetary Geography
- **3D Sentiment Space**:
  - **X-Axis**: Sentiment Polarity (-1.0 Negative to +1.0 Positive)
  - **Y-Axis**: Subjectivity Index (0.0 Objective to 1.0 Subjective)
  - **Z-Axis**: Review Word Count (Length/Detail)
  - **Color**: Star Rating Score (1 to 5)
- **3D Orthographic Earth Globe**: Visualizing international guest geographic origin nodes and regional sentiment satisfaction levels.

### ⏳ 3. 4D Decade Experience Evolution
- **4D Spatio-Temporal Projection**:
  - **Dim 1 (X)**: Sentiment Polarity
  - **Dim 2 (Y)**: Review Word Count
  - **Dim 3 (Z)**: Star Rating
  - **Dim 4 (Color)**: Park Branch (California, Paris, Hong Kong)
  - **Dim 5 (Size)**: Subjectivity Score
  - **Dim 6 (Time / Frame Animation)**: Yearly Timeline (2011 through 2019)
- Observe how park guest sentiment and review verbosity adapted as park operations evolved across the decade.

### ✨ 4. Real-Time NLP Review Rating Predictor
- Input or paste custom park reviews to receive real-time sentiment polarity scoring, diagnostic sentiment tags, and machine-learning predicted star ratings (1-5).

## 🚀 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akshaysharma2005/disneyland-sentiment-nlp-explorer.git
   cd disneyland-sentiment-nlp-explorer
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the Dashboard**:
   ```bash
   streamlit run app.py
   ```

4. Open `http://localhost:8501`.
